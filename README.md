# ليبيا... جمال لا يُروى — صفحة عرض تفاعلية 

صفحة هبوط (Landing Page) تفاعلية بتصميم Slideshow، تعرض أبرز المعالم السياحية
والتاريخية في ليبيا. نموذج من "بنيان" لعرض قدرات تصميم واجهات تفاعلية عربية.

## المميزات
- سلايدر صور كامل الشاشة مع تأثيرات انتقال
- تصميم عربي كامل (RTL) بخط Cairo
- متجاوب مع جميع أحجام الشاشات

## التقنيات المستخدمة
HTML, CSS, JavaScript
